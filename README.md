# Upcoming Projects

This repository provides an overview of projects developed by GeaStack Community that are planned or being considered for future public release.

It serves as a central directory of selected projects, allowing visitors to learn about them before their public repositories become available.

**The information in this repository is provided for informational purposes only. A project's inclusion does not guarantee its completion, public release, or availability on a specific date.**

## Purpose

Projects may remain in private development for an extended period before they are ready for public release.

This repository introduces selected projects, explains their general purpose, and shares information that is suitable for public disclosure about their development and release plans, without exposing private development resources or confidential information.

Its goals are to:

- Introduce projects planned or considered for future public release.
- Explain the purpose and intended audience of each project.
- Share general development status and release plans.
- Provide estimated release timeframes when available.
- Link to public repositories and related documentation when available.

This repository is an informational directory, not a development workspace or a project submission platform.

## Project Information

Project listings may include the following information:

- **Name:** The project's name.
- **Description:** An overview of the project's purpose and goals.
- **Status:** The project's current development status.
- **Release Plan:** Whether a public release is planned, under consideration, or has already occurred.
- **Expected Release:** The estimated release timeframe, when available.
- **Repository:** A link to the project's public repository, when available.

## Project Status

The following status labels describe the development status of listed projects.

| Status | Description |
| --- | --- |
| `Planning` | The project is in the planning or design stage. |
| `In Development` | The project is under active development. |
| `Preparing for Release` | The project is being prepared for a planned public release. |
| `Coming Soon` | The public release is approaching, although the exact release date may change. |
| `Released` | The project has been made publicly available. |
| `On Hold` | Development or release preparation is temporarily paused. |

These labels describe the publicly reported status of a project and may not reflect every detail of its internal development process.

## Release Plans

A project's inclusion in this repository does not constitute a commitment to release it publicly.

Release plans are described using the following terms:

| Term | Meaning |
| --- | --- |
| `Planned` | A public release is planned. |
| `Under Consideration` | A public release is being considered but has not been confirmed. |
| `Released` | The project is publicly available. |

Release dates and timeframes are estimates and may change.

Projects may change significantly during development. Their scope, features, licensing, and release plans may be revised. Projects may also be delayed, postponed, or canceled.

Unless explicitly stated otherwise, release dates and feature descriptions are provisional.

## Information Disclosure

This repository is public. Its contents are limited to information suitable for public disclosure.

### Public Information

Project listings may include:

- Project names and descriptions.
- General project goals and intended use cases.
- Features approved for public disclosure.
- General development status.
- Public release plans and estimated timeframes.
- Links to public repositories, documentation, and other relevant resources.

### Non-Public Information

Private development resources and confidential information are not included in this directory. This includes:

- Private repository URLs and internal development resources.
- Unreleased source code and confidential implementation details.
- Internal design documents and non-public technical specifications.
- Private issues, pull requests, discussions, and internal decision-making records.
- Credentials, access tokens, private keys, and other secrets.
- Unpatched security vulnerabilities and sensitive security details.
- Confidential business information and information subject to non-disclosure obligations.
- Personal information that is not appropriate for public disclosure.
- Unannounced partnerships or other confidential announcements.

The presence of information in a private development environment does not imply that it is suitable for public disclosure.

## Public Release

A project's listing is separate from the public release of its source code and development resources.

When a project becomes publicly available, its listing may include links to its public repository and related documentation.

Projects that are postponed, canceled, or no longer intended for public release may be removed from this directory.

## Disclaimer

Project descriptions, development statuses, release plans, and estimated timeframes are provided for informational purposes only.

Features may change, timelines may be revised, and projects may be delayed or canceled.

Inclusion in this repository does not guarantee that a project will be completed, released publicly, maintained indefinitely, or distributed under any particular license.

Licensing, availability, contribution, and usage terms are described in the relevant project's public repository or accompanying documentation, where available.
